JSON Formatter

Validate, format, and minify JSON from API responses and configuration files.

Processed in your browser. Your input is not uploaded.

01

Input

Validates with JSON.parse. Output is shown as text; it is never executed.

02

Output

Run the tool to see the result.

Limits

Comments and trailing commas are not valid JSON. Formatting uses JavaScript's number representation, so integers beyond its safe precision may change; keep large IDs as strings. Duplicate object keys follow JSON.parse behavior: the last value wins. Input is limited to one million characters.
