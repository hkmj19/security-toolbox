Telegram Bot Checker

Check your own bot token with Telegram and inspect the bot identity returned by getMe.

Sends the token directly to Telegram when you run the check.

01

Input

"Check with Telegram" sends this token directly to api.telegram.org. It is not saved by this page. Only use your own token.

Clear the field when finished.

02

Output

Run the tool to see the result.

What this checks

getMe returns the bot identity linked to a working token. It does not audit the bot or read conversations. Browser restrictions or network errors can prevent a check. Telegram requires the token in the API request URL; keep developer tools and local network logs private.
