Unicode Lookalikes

Compare similar-looking characters and inspect the Unicode code points in a string.

Choose a replacement under each character. Scroll the character list sideways on small screens.



About these characters
This is a curated set of lookalikes, not the complete Unicode confusables database. Appearance depends on the font. Generated text may not be a valid or registrable domain. This tool does not visit the generated text as a URL.
